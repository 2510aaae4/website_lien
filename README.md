# 連思涵醫師 · 衛教網站（設計預覽）

心臟專科 × 高齡醫學品牌衛教網站，暖色系 Editorial Clinic 風格。
純靜態網站，可直接以 GitHub Pages / Netlify / Cloudflare Pages 部署。

## 本機預覽
雙擊 `index.html` 即可開啟；或在本資料夾執行：
```
py -m http.server 8123
```
然後開 http://localhost:8123/

## 頁面
- index.html 首頁
- articles.html 衛教文章列表
- article.html 單篇文章
- new.html 新增文章（文字/圖片/影片，原型存於瀏覽器 localStorage）
